# PifOS

**Track Every Lead From First Click to Closed Deal**

PifOS is an AI-powered sales operating system for tracking customer journeys, managing leads, and growing revenue — all from one dashboard.

## Live App

[pifos.io](https://pifos.io)

## Stack

- Vanilla HTML/CSS/JS — single file, no framework
- Supabase Auth — multi-user login
- Vercel — auto-deploy on push to main
- Chart.js — revenue and funnel charts

## Deploy

Every push to `main` deploys automatically via Vercel.
